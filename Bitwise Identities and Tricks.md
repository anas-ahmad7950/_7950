Given an array $a$ of $n$ positive integers, we can calculate the following expression $\min_{1 \le i < j \le n} a_i \oplus a_j$ by sorting the array then calculating the following $\min_{1 \le i < n} a_i \oplus a_{i + 1}$.

To prove this, lets assume we have three positive integers $x$, $y$ and $z$, where $x < y < z$. let $k$ be the most significant bit position where $x$ and $z$ differ. It is obvious that the $k^{th}$ bit of $x$ is equal to $0$ while the $k^{th}$ bit of $z$ is equal to $1$ (since $x < z$). All bits greater than $k$ are identical for $x$, $y$ (because it lies between $x$ and $z$) and $z$. For the $k^{th}$ of $y$, it can be $0$ or $1$. If it is equal to $0$ then $x \oplus y < x \oplus z$ because $0 \oplus 0 < 0 \oplus 1$. If it is $1$ then $y \oplus z < x \oplus z$ because $1 \oplus 1 < 0 \oplus 1$.
